with_item

1. Modify motd

---
- name: Modify Motd
  hosts: target
  become: yes
  gather_facts: true
  tasks:
    - name: Modify Motd
      ansible.builtin.copy:
        dest: /etc/motd
        content: "Welcome to {{ item }}"
      with_items:
           - Amazon
           - Ubuntu
      when: ansible_distribution == item

    - name: Collect motd
      ansible.builtin.slurp:
        path: /etc/motd
      register: motd_content

    - name: Display motd
      ansible.builtin.debug:
        msg: "{{ motd_content['content'] | b64decode }}"

3. Installation of multiple packages using loop
---
- name: Install multiple packages
  hosts: target
  become: yes
  tasks:
    - name: Install multiple packages (Linux)
      ansible.builtin.yum:
           name: "{{ item}}" 
           state: present 
      loop: 
        - httpd
        - vim
        - yamllint
      when: ansible_distribution == 'Amazon'

    - name: Install multiple packages (Ubuntu)
      ansible.builtin.apt:
            name: "{{ item}}"
            state: present
       loop:
          - apache2
          - vim
          - yammlint

4. with_dict 

with_dict is legacy. The recommended modern pattern is loop: "{{ mydict | dict2items }}". I’ll show both so your learners understand old playbooks and write new ones correctly.

---
- name: Demo with_dict - print key/value
  hosts: target
  gather_facts: false
  vars:
    app_config:
        app_name: "test-api"
        port: 8080
        debug: true
  tasks:
     - name: Show each config item
       ansible.builtin.debug:
         msg: "Key: {{ item.key}}, Value: {{ item.value}}"
       with_dict: "{{ app_config }}"
...
========================================================================

Managing Package
---
- name: Package Management using dict2items
  hosts: target
  vars_files:
     - packages.yaml
  become: yes
  tasks:
    - name: Install packages
      ansible.builtin.package:
         name: "{{ item.key }}"
         state: "{{ item.value}}"
      loop: "{{ packages | dict2items }}"

with_random_choice:

Random SSH banner quote (per session variety)

- name: Random SSH banner quote
  hosts: linux
  become: true
  vars:
    quotes:
      - "Automation is the future."
      - "Trust but verify."
      - "Ship small, ship often."
      - "Measure twice, deploy once."
  tasks:
    - name: Pick a quote
      set_fact:
        login_quote: "{{ item }}"
      with_random_choice: "{{ quotes }}"

    - name: Configure issue.net
      ansible.builtin.copy:
        dest: /etc/issue.net
        content: "Authorized access only.\n{{ login_quote }}\n"

    - name: Ensure SSH shows banners
      ansible.builtin.lineinfile:
        path: /etc/ssh/sshd_config
        regexp: '^Banner'
        line: 'Banner /etc/issue.net'
      notify: Restart SSH

  handlers:
    - name: Restart SSH
      ansible.builtin.service:
        name: ssh
        state: restarted
...
